Help & guidance

Simple steps for the most common EcoReceipt tasks.

＋

Record a new order

  1. Open New transaction.
  2. Enter the customer, store, and delivery date.
  3. Set the quantity for each requested product.
  4. Review the live subtotal, discount, and total.
  5. Save to generate a receipt and update stock.
▧

Manage inventory

  1. Open Inventory to review available products.
  2. Search by product name or SKU.
  3. Use the form to add a product with a unique SKU.
  4. Check low stock before accepting a large order.
▤

Print a receipt

  1. Open Orders & receipts.
  2. Select View beside the correct order.
  3. Choose Print receipt.
  4. Use the browser print dialog or save as PDF.
☷

Prepare a delivery

  1. Open Delivery checklist.
  2. Check each item after it is physically picked.
  3. Open the order receipt if you need full details.
  4. Authorized staff can update the fulfillment status.

Designed for clear, low-error work

Visible system status

Success messages, stock counts, and order status help users understand what happened.

Error prevention

Quantity limits, required fields, and stock validation prevent common order-entry mistakes.

Recognition over recall

Labels, searchable lists, and visible product SKUs reduce the need to remember details.

Consistent navigation

The same sidebar and page patterns help users move between tasks predictably.
